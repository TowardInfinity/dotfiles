# Splits

| Keys | Action | Mode |
| --- | --- | --- |
| `Space s v` | Split vertically | `n` |
| `Space s s` | Split horizontally | `n` |
| `Space s c` | Close the split | `n` |
| `Ctrl ↑↓←→` | Resize the split | `n` |
